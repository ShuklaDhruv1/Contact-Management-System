## 📇 About the Project

A Java console application that helps users manage personal contacts using **Object-Oriented Programming and File Handling**.

## ⚡ Features

- ➕ Add new contacts
- 📋 View all contacts
- 🔍 Search contacts by name
- ✏️ Update phone and email
- 🗑️ Delete contacts
- 💾 Save contacts to a text file
- 🔄 Load saved contacts after restarting

## 🧠 Concepts Used

| Concept | Purpose |
|---|---|
| Classes and Objects | Represent contacts |
| Encapsulation | Keep contact fields private |
| ArrayList | Store contacts in memory |
| Methods | Organize operations |
| File Handling | Read and write contacts |
| Exception Handling | Handle file errors |

## 📂 Project Structure

```text
Contact-Management-System/
├── Contact.java
├── ContactFileHandler.java
├── ContactManagementSystem.java
├── contacts.txt        # Created when contacts are saved
└── README.md
```

## 🚀 How to Run

**Compile:**

```bash
javac Contact.java ContactFileHandler.java ContactManagementSystem.java
```

**Run:**

```bash
java ContactManagementSystem
```

## 💾 How Persistence Works

```text
       Start Application
              |
              v
       Load contacts.txt
              |
              v
       Manage Contacts
       /      |      \
     Add    Update   Delete
       \      |      /
              v
       Save contacts.txt
              |
              v
       Data persists after restart
```
